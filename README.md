
# 社媒带货文案 Skill · 展示版

此作品由“偏序工作室”提供。

把商品资料写成一篇清楚、自然的中文带货短文案。本仓库提供可本地体验的精简版本；商业完整版 v3 由偏序工作室线上网店另行授权交付。

## 体验版包含什么

- 从已有资料提取商品、受众和一个基础卖点。
- 生成一个标题、一篇短图文和一句行动引导。
- 保留事实核对与缺失信息处理，避免编造体验、功效和销量。

| 能力 | 本展示版 | 商业完整版 v3 |
| --- | --- | --- |
| 基础图文写作 | 一个标题与一篇短文 | 默认三个角度标题、完整图文或口播稿 |
| 行动引导 | 一条基础引导 | 直接版与轻促版 |
| 转化策划 | 一个基础卖点 | 转化角度卡、卖点放大、顾虑化解 |
| 表达素材 | 基础写法 | 钩子库、标题公式、情绪强度选择 |
| 渠道适配 | 基础图文体验 | 图文、口播、朋友圈、社群等场景 |
| 后续优化 | 未包含专项流程 | 数据复盘与迭代指引 |

展示版通过精简文件内容区分能力，没有账号验证或技术锁。完整版未包含在本仓库中。不同模型的实际输出会有差异，均不保证流量或成交。

## 使用方法

将 `social-commerce-copy-demo` 文件夹放入所用工具支持的技能目录，按该工具的方式启用；也可以将其中的 `SKILL.md` 作为规则文件供支持此方式的模型读取。

提供真实商品资料后提出写作需求，例如：

```text
使用 social-commerce-copy-demo，帮我写一篇商品图文。
商品：桌面收纳托盘
人群与场景：想整理书桌零碎物品的租房用户
已知事实：尺寸20×12×2cm，PP材质，售价19元
购买入口：店铺商品页
语气：自然、简洁
```

以上仅为虚构演示设定，不对应在售商品；实际使用时请换成可核对的商品资料。价格和尺寸本身不能证明耐用、环保或特定容量。
